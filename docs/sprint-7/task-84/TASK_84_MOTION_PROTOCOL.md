# Task 84 動作流程

每個 required run 依序執行，scenario 前 Reset diagnostics，結束複製 JSON並記錄 pass/concern/blocker/not-run：

1. 全身 stationary standing 10 秒：skeleton/angle jitter與alignment。
2. 三次 slow squat：continuity、左右 knee、freeze。
3. 三次 faster squat：trailing、Task 77 lag/attenuation。
4. 側或斜向 knee extension/flexion：廣角度、near-straight、不隨機 0°。
5. Arm movement：skeleton 正確、knee label不被無關動作擾亂。
6. 短暫遮住 knee/ankle，再長遮擋：degraded/held→unavailable、無永久 stale number。
7. 離開畫面超過 stale threshold後再進入：overlay clears/recovery。
8. Front camera 舉左手／動左腿：mirror與metric identity。
9. 可支援時 front→rear→front：立即清舊 overlay、session clean。
10. portrait→landscape→portrait：alignment、controls、resize。
11. 錄製至少30秒後 Review：play/pause/seek forward/backward、非 live、非錯誤 mirror。
12. Android與iOS各至少3分鐘：混合 movement/occlusion/orientation，記錄 responsiveness、heat、memory趨勢與recovery。

不得從上述觀察推論臨床或實驗室準確度；Task 77 調參需多於一次／一裝置的可重現 before/after。
